16-Bit Single-Cycle CPU
VHDLVivadoFPGADigital Design
MEM[0x03]
  • Designed and implemented a complete single-cycle CPU in VHDL, integrating a program counter, instruction memory, data memory, register file, ALU, and control unit into a fully functional processor.
  • Extended the CPU's instruction set to support control flow instructions (branch-not-equal and jump), requiring custom multiplexer logic and control signal design to correctly route register operands and update the program counter.
  • Debugged complex datapath issues using RTL schematic analysis and simulation waveforms, resolving synthesis and timing issues including memory addressing errors, byte-endianness mismatches, and signal reset conflicts.
  • Verified complete instruction execution and control flow behavior through simulation testbenches, confirming correct data flow, branching, and jumping across all supported instructions.
  • Collaborated with a team of 3 to integrate previously developed components (ALU, register file, control unit) into a unified system architecture, applying modular design principles from earlier lab work.
